01Pipeline

stage 1

Transcript

Pulled straight from YouTube. Any language with captions works.

stage 2

Condense

The transcript becomes a deck: thesis, key points, headline number, quote, timeline, closer. Same shape every time.

stage 3

File

Sorted onto one topic shelf, tagged from your vocabulary. New tags are proposed, never auto-applied.

stage 4

Verify

Optional: the comment section is read against the deck. Disputed claims get caveats.

02Spec

PropertyValue
Summary form6 sections, fixed order. Once you've read one, you can skim any of them.
Deep linksEvery key point → timestamp in the source video. Verify, don't trust.
LibraryTopic shelves (one per video) + tags (many). AI-attached tags are marked and revertible in bulk.
Queueunread / reading / read, plus starred. An inbox, not a feed.
Community checkOn demand, per video. Needs 3+ substantive comments to say anything at all — praise and memes don't count.
AccountsNone. Single user, self-hosted, your database.

03Details that matter

  • Transcripts are stored, so summaries re-render offline without touching YouTube again.
  • Comment text is treated as untrusted input — sanitised, fenced, and never shown to the tagger.
  • Quotes from comments are verified verbatim against the scraped thread before they're shown.
  • A failed tagging run never loses the summary. You keep the deck and file it by hand.
  • No autoplay, no thumbnails, no recommendations. The queue only contains what you put in it.
  • One import ≈ 35 seconds. A three-hour podcast reads in about six minutes.

The demo has a dozen real summaries loaded. No sign-up.
